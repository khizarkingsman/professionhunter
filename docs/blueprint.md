# **App Name**: HandyConnect

## Core Features:

- User Authentication: Secure registration and login for both service seekers and workers.
- Profile Management: Workers create and manage profiles, including profession, photo, bio, experience, and contact information. Service seekers create a profile with contact information.
- Location Based Matching: Match service seekers with workers based on their location.  Only users in the same city will be shown to each other.
- In-App Chat: Enable direct communication between service seekers and workers via a built-in chat feature. An LLM tool decides when to inject some relevant article or how-to snippet into the conversation based on its analysis of chat history.
- Ratings and Reviews: Allow service seekers to rate and review workers, with workers able to respond to comments.
- Contact Options: Display worker contact information and provide options for in-app chat and WhatsApp contact.

## Style Guidelines:

- Primary color: Pale blue (#ADD8E6) to convey trust and reliability, inspired by the professional and helpful nature of the app.
- Background color: Light gray (#F0F0F0) for a clean and unobtrusive backdrop.
- Accent color: Soft lavender (#E6E6FA) for interactive elements, offering a subtle contrast.
- Body and headline font: 'PT Sans', a sans-serif typeface combining warmth and modernity, will be used across the application to ensure content is approachable.
- Use clean, simple icons to represent different professions (plumbing, electrical, etc.), and to show key interactive features, providing an instantly recognizable, consistent and familiar user experience. Referencing icons on the home screen shown in the image.
- Implement a clean and intuitive layout with clear sections for browsing, profiles, and chat. The home screen should have an array of rectangles like the sample image shows.
